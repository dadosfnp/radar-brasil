{% trans "Como avaliamos o Federalismo Climático?" %}

{% trans "O Radar Brasil: Federalismo Climático sintetiza o desempenho dos entes federativos em uma única Nota País. Essa nota é resultado de uma avaliação em funil: partimos da análise de cada componente para, depois, chegar à síntese do todo." %}

{% trans "Cada componente do federalismo climático é avaliado individualmente, a partir de critérios e parâmetros de nível. Os resultados dessas avaliações são agregados nos eixos analíticos e, por fim, consolidados na Nota País." %}

{% trans "Eixo" %}

{% trans "O Radar Brasil avalia 4 eixos temáticos: Governança, Políticas e Planos, Programas e Linhas de Financiamento. Esta separação permite qualificar a análise de componentes que possuem lógica institucional distinta e confrontar os eixos entre si para extrair novas camadas de análise." %}

{% trans "Critério" %}

{% trans "Um critério corresponde a uma dimensão específica de análise dentro de cada eixo. A definição de múltiplos critérios por eixo responde à necessidade de decompor o componente em partes menores, mensuráveis e analiticamente distintas entre si, de três a cinco critérios." %}

{% trans "Parâmetro" %}

{% trans "O parâmetro define como diferenciar os graus de maturidade de cada critério. É uma determinante objetiva associada a cada um dos cinco níveis da escala. Diante de um determinado dado, o parâmetro indica em qual nível aquele caso deve ser classificado." %}

{% trans "Componente" %}

{% trans "Um componente representa um espaço de governança, política, plano, programa ou linha de financiamento avaliado. Cada componente recebe uma avaliação individual por critério, que é depois agregada ao eixo correspondente." %}

{% trans "Conheça os critérios de análise para cada eixo" %} {% trans "Clique em um critério para ver sua definição e os parâmetros de avaliação" %}
